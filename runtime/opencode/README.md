# Running AI Job Agent in OpenCode

[OpenCode](https://github.com/opencode-ai) is an open-source terminal agent. AI Job Agent runs out-of-the-box in OpenCode using standard CLI commands and Agent Skills.

---

## 1. Quickstart
```bash
git clone https://github.com/QaliAI/ai-job-agent.git
cd ai-job-agent
python scripts/setup.py
opencode
```

## 2. In-Session Tasks
Inside OpenCode:
* `"Run daily_workflow.py and show me my morning report."`
* `"Check system health with doctor.py."`
* `"Tailor my resume for this posting: <URL>"`
