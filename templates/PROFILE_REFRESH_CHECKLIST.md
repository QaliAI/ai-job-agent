# Candidate Brand Refresh Checklist

Use this checklist before treating a refreshed base résumé or LinkedIn profile as application-ready.

## Identity and chronology
- [ ] Exact employer names verified
- [ ] Exact official titles verified
- [ ] Start/end dates verified
- [ ] Education institution/program/dates verified
- [ ] Contact links current

## Recent work
- [ ] Current consulting/fractional work represented
- [ ] Strongest shipped AI/product builds represented
- [ ] Current client leadership represented where appropriate
- [ ] Obsolete tools/projects removed from headline emphasis

## Evidence quality
- [ ] Every metric has a source
- [ ] System-wide scope is not misrepresented as personal causation
- [ ] No invented technical depth
- [ ] No inferred certifications or credentials
- [ ] Public product links resolve

## Positioning
- [ ] One umbrella narrative
- [ ] Opportunity tracks remain distinct
- [ ] Base résumé is readable by a human, not keyword-stuffed
- [ ] LinkedIn headline uses market-recognizable language
- [ ] LinkedIn About explains business value, implementation depth, and target work
- [ ] Featured section recommendations include concrete proof of work

## Final QA
- [ ] Claim check passes
- [ ] Profile gaps file is empty or accepted by the candidate
