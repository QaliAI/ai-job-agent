# Candidate Data Directory

> **Privacy Notice**: This directory is where your private career data lives on your local machine.
>
> All personal files in this folder are **automatically ignored by `.gitignore`** so that your real resume, phone number, email address, salary history, and personal stories are **never** accidentally uploaded to GitHub or shared publicly.

---

## File Structure

When you complete the initial setup (either via `python scripts/setup.py` or your AI agent), this directory will contain:

* `MASTER_PROFILE.md` — Your complete, verified factual career record (work history, titles, dates, verified skills).
* `SEARCH_PREFERENCES.md` — What you are looking for (target roles, locations, remote/hybrid, salary minimum, excluded companies).
* `VERIFIED_ACHIEVEMENTS.md` — Bullet points and metrics you have personally confirmed.
* `CAREER_STORIES.md` — STAR-method narratives of projects and problems you have solved.
* `skills.json` — Structured taxonomy of your proven technical and domain skills.

---

## Templates

If you wish to create these files manually without running the setup wizard, copy the starter templates from the [`templates/`](../templates/) directory into this folder.
