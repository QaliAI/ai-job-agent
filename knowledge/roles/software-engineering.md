# Role Family Guide: Software & Infrastructure Engineering

## 1. Industry Conventions & ATS Expectations
* **Format Priority**: Reverse-chronological, crisp single- or two-page format with clear technical skills categorization (Languages, Frameworks, Cloud, Databases).
* **High-Signal Evidence**:
  - Quantified scale: Requests per second (RPS), daily active users (DAU), data volume (TB/PB), latency percentiles (p50, p95, p99), cluster node count.
  - Architectural complexity: Distributed consensus, event streaming, caching layers, microservice decomposition, zero-downtime database migrations.
  - Engineering practices: Test coverage %, CI/CD pipeline velocity, infrastructure-as-code (IaC), incident response / MTTR reduction.

## 2. Keywords & Core Competencies
* **Languages**: Python, Go, Rust, Java, C++, TypeScript, SQL
* **Data Systems**: PostgreSQL, MySQL, Redis, Kafka, Cassandra, DynamoDB, MongoDB, Elasticsearch
* **Infrastructure**: AWS, GCP, Azure, Docker, Kubernetes, Terraform, Helm, Prometheus, Datadog

## 3. Grounded Tailoring Rules
* Reorder bullets to lead with the exact technologies and architectural problems mentioned in the target Job Description.
* Highlight specific metrics from `VERIFIED_ACHIEVEMENTS.md` that prove capability with the job's scale.
* DO NOT claim experience in languages or distributed systems not verified in candidate profile truth.
