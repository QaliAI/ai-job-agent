# Role Family Guide: Data Science & Machine Learning

## 1. Industry Conventions & ATS Expectations
* **Format Priority**: Technical competencies separated into Modeling/Algorithms, Data Engineering, and Production MLOps.
* **High-Signal Evidence**:
  - Model metrics: AUC-ROC, F1-score, precision/recall, MAE/RMSE, inference latency (ms), training cost reduction.
  - Business impact: Lift in recommendation CTR, fraud dollars prevented, forecast error reduction.
  - Production engineering: Feature stores, real-time inference pipelines, model monitoring, PyTorch/TensorFlow deployment.

## 2. Keywords & Core Competencies
* **Tooling**: Python, PyTorch, Scikit-learn, SQL, Spark, Airflow, MLflow, Ray, Hugging Face, Transformers
* **Disciplines**: Deep Learning, NLP / LLM fine-tuning, Computer Vision, Causal Inference, Time-Series Forecasting
